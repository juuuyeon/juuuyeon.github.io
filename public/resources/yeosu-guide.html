여수새고막 어드민 운영 가이드

대상: 비개발자 운영 담당자 · 주소: https://(사이트)/admin · 최종 갱신: 2026-07-16 (기준 main @ 64dc7dd)

핵심 원칙 — 편집 전에는 공개 화면이 그대로 유지됩니다. 저장한 항목만 바뀌고, 언제든 [기본값으로 초기화]로 되돌릴 수 있습니다(무위험).

시연용 흐름 정리는 여수새고막_어드민_시연플로우.md 참고.

1. 로그인

  • /admin 접속 → 로그인 화면. 관리자는 이메일 칸을 비우고 비밀번호만 입력합니다(이메일을 채우면 직원 계정 검증으로 빠져 실패). 직원 계정은 이메일+비밀번호.
  • 세션은 12시간 유지됩니다. 공용 PC에서는 작업 후 좌하단 로그아웃을 꼭 누르세요.
  • 역할 두 가지: 어드민(모든 메뉴 + 직원 계정 관리 + 문의) / 편집자(콘텐츠·브랜드·뉴스·미디어·헤더푸터·카테고리·채널·SEO·언어팩. 문의 관리·설정 제외).
  • 비밀번호를 10분 내 10회 틀리면 10분간 차단됩니다. 마스터 비밀번호는 서버 ADMIN_PASSWORD 환경변수로 변경합니다.

2. 대시보드 읽는 법

상단 카드 4개 — 신규 문의 / 게시 중 뉴스 / 브랜드·제품 수 / 운영중 채널(클릭하면 해당 메뉴로 이동). 아래 좌: 최근 문의, 우: 최근 작업 이력(무엇이 언제 바뀌었는지 자동 기록 — 작성자는 기록되지 않습니다).

3. 콘텐츠 수정 (콘텐츠 관리)

  1. 상단에서 페이지 선택. 18개 페이지가 공개 GNB 구조대로 묶여 있습니다 — 메인(1) · 회사소개(CEO 인사말·회사개요·생산공정·품질신뢰·회사연혁·조직도·수출실적, 7) · 브랜드(엄지네·칠산·여수올림, 3) · 제품(제품 소개, 1) · 수출정보(OEM/ODM·카탈로그·수출국·인증, 4) · 문의(1) · 전역(회사 정보, 1).
  2. 왼쪽 실시간 미리보기(PC/모바일 전환, [새 탭 ↗])를 보며, 오른쪽 블록 목록에서 [편집] 클릭 → 오른쪽 드로어에서 내용 입력 → [저장]. 저장 즉시 미리보기·공개 화면에 반영됩니다(배포 불필요).
  3. 순서 변경: 블록 앞 ⠿ 핸들을 끌어 놓으면 그 순간 자동 저장됩니다(별도 저장 버튼 없음 — 순서 저장 중… 표시가 잠깐 뜹니다). 되돌리려면 [기본 순서로].
  4. 섹션 추가: 목록 하단 [+ 섹션 추가] → 문단·이미지·CTA 배너 중 선택.
  5. 되돌리기: 수정한 블록을 다시 열면 [기본값으로 초기화] 버튼이 생깁니다.
  6. 섹션 링크(메인 전용): 블록 옆 🔗 /#... 칩을 누르면 주소가 복사됩니다. 헤더·푸터 메뉴의 링크에 붙여넣으면 클릭 시 해당 섹션으로 스크롤됩니다.
  • 배지 안내 — 고정(위치 이동 불가, 핸들이 회색) · 순서·노출만(내용은 전용 메뉴나 코드에서 관리) · 수정됨(기본값과 달라짐) · 추가됨(직접 추가한 섹션) · 공개 연동 예정(저장은 되지만 공개 반영 전).
  • 주의: 순서 변경과 추가 섹션의 공개 반영은 메인 페이지만 지원합니다(서브페이지에서는 화면 하단에 안내가 뜹니다). 내용·이미지 편집은 전 페이지 반영됩니다.

4. 브랜드·제품 추가

  • 상단 브랜드 탭 선택 → [+ 제품 추가]로 제품명·태그(예: NEW · 160g/300g · 수출가능)·판매 상태(판매중/출시예정/단종)·카드 이미지 입력. 신규 제품은 이미지 업로드를 권장합니다(기존 제품은 비우면 원본 유지).
  • [+ 브랜드]로 브랜드 자체를 추가할 수 있습니다(밀키트 신제품은 소속 브랜드에서 [+ 제품 추가]). 제품은 ▲▼로 순서 변경.
  • 왼쪽 미리보기는 항상 제품 허브(/products) 로 고정입니다 — 브랜드·제품 편집이 반영되는 화면이기 때문입니다.
  • IA 확장 규칙 자동 안내: 제품이 5종 이상이면 라인업이 자동으로 슬라이더 전환, GNB 항목 수를 N/8로 표시(초과 시 경고). 브랜드 9개+ 또는 단일 브랜드 제품 20종+이면 IA 재검토 알림이 뜹니다.

5. 뉴스·공지 발행

  • [+ 새 글] → 분류(공지/보도/전시회)·제목·게시일·내용·대표 이미지(공개 목록 썸네일)·연결 링크(보도자료 원문 등, 선택) 입력.
  • 목록의 노출 토글로 게시/숨김, [삭제]로 제거. 등록한 글은 공개 뉴스 목록 상단에 바로 게시됩니다.

6. 미디어 업로드 규칙

  • 미디어 메뉴에 이미지·영상을 끌어다 놓거나 [파일 선택](여러 개 가능, 최대 20MB). 콘텐츠 편집 중 이미지 필드에서 올린 파일도 여기에 자동으로 모입니다.
  • SVG는 보안상 업로드할 수 없습니다 — PNG·JPG·WebP를 사용하세요.
  • 각 파일 [URL 복사]로 다른 곳에 재사용, [삭제]로 제거(사용 중 화면에서는 이미지가 깨지니 주의).

7. 헤더·푸터

  • 왼쪽 라이브 미리보기는 타이핑에 맞춰 즉시 갱신됩니다(저장 전에도). 실제 화면은 반응형으로 배치됩니다.
  • 헤더 탭 — 로고 이미지(비우면 기본 워드마크)·브랜드 텍스트, 메뉴 색/강조 색, 문의하기 버튼 노출 토글, 메뉴바(GNB): ⠿ 핸들로 순서 변경(2단계까지), [+ 상위 메뉴 추가] / [+ 하위 메뉴 추가]. 각 메뉴는 라벨(국문/영문)·링크·열기(본문/새 창)·노출을 설정합니다.
  • 푸터 탭 — 푸터 로고, 대표 이메일, Copyright, 사무소(이름 + 라벨·값 행 추가), 패밀리 브랜드 링크, 소셜, 하단 링크(약관 등).
  • 콘텐츠 관리와 달리 [저장]을 눌러야 반영됩니다. 변경이 있으면 상단에 저장되지 않은 변경 표시와 [되돌리기]·[저장]이 나타납니다.

8. 카테고리 관리

  • 제품 허브(/products)의 카테고리 탭(전체·간편식·식사류·원물·신제품 예고) 순서·노출·라벨을 관리합니다.
  • 좌측 노출 (탭 순서) / 우측 숨김 2컬럼. 카드를 오른쪽으로 끌면 숨김, 왼쪽으로 끌면 다시 노출 — 별도 토글 없이 드래그가 노출 제어입니다. 라벨(국문/영문)은 카드에서 바로 수정.
  • 변경 후 [저장]을 눌러야 반영됩니다(헤더·푸터와 동일 방식). 신제품 예고는 예고 제품이 있을 때만 공개에 표시됩니다.

9. 문의 처리 절차 (어드민 전용)

  • 상태 탭(전체/신규/상담중/완료/스팸) + 카운트, 이름·회사·내용 검색, 유형 필터(바이어/국내/OEM/바우처).
  • 문의 클릭 → 드로어에서 처리 상태·담당자·상담 메모(내부용) 입력 후 [저장]. 담당자 미배정은 목록에 회색 표시.
  • [CSV 내보내기]로 현재 목록을 엑셀용 파일로 저장. (공개 문의 폼 제출이 곧바로 여기에 쌓입니다.)

10. 마케팅 채널 · UTM

  • 판매몰/SNS/광고/오프라인 채널을 등록하고 URL·UTM 소스(예: utm_source=smartstore)·상태(운영중/준비중/중단)를 관리. 운영중 채널의 외부 URL은 자동으로 사이트 구조화데이터(공식 채널 정보)에 연결됩니다.

11. 검색 노출 (SEO·AEO·GEO)

  • 검색엔진 메타(타이틀/설명/키워드/공유 이미지)를 한국어·English 각각 저장(탭 전환). 비워 두면 기본값이 그대로 쓰입니다.
  • AI 크롤러 정책: 허용(AI 검색 노출, 권장) / 차단 선택 → robots.txt에 반영.
  • llms.txt(AI 요약)·구조화데이터·hreflang은 자동 생성되며 브랜드·제품·뉴스 수정 시 자동 갱신됩니다.

12. 통계

  • 기간 선택: 프리셋(오늘/이번 주/이번 달), 월 단위 이동(← 이전 달 / 다음 달 →), 또는 시작일·종료일 직접 지정 후 [적용]. 날짜 기준은 한국 시간(KST)입니다.
  • 자체통계 탭 — 기간 문의 / 신규(미처리) / 처리 완료(완료율) / 일평균 KPI + 상태별 분포(도넛) + 일별 문의 추이 + 문의 유형별 + 마케팅 동의율 + 최근 문의 목록. 실제 문의 데이터 기준입니다.
  • 방문·유입 탭 — 총 방문 / 일평균 / 최다 유입경로 + 일별 방문 추이 + 상위 유입경로 + 상위 페이지. 자체 방문 집계 기준이며 개인정보·쿠키는 수집하지 않습니다(경로·리퍼러·시각만).
  • GA4 탭 — 현재 리포트 준비중입니다. 측정 ID·API Secret·속성 ID를 저장해 둘 수는 있으나, GA4 유입 리포트 연동은 다음 단계입니다.

13. 언어팩(i18n)

  • 메뉴·푸터·히어로 등 사이트 공통 문구를 KO/EN 나란히 편집. 상단 버튼으로 분류를 전환합니다.
  • 원본과 다른 값만 저장되고, 원본과 같아지면 자동으로 원본을 따릅니다. 수정된 키는 파란 ● 표시, [전체 초기화]로 일괄 복구. 저장 즉시 공개 사이트(KO·EN)에 반영됩니다.
  • 리스트 구조 항목은 여기서 편집하지 않고 콘텐츠 관리에서 다룹니다.

14. 설정 (어드민 전용)

  • 계정·권한 — 직원 계정 [+ 직원 추가](이름·이메일·역할·초기 비밀번호), 역할(어드민/편집자), 활성 토글, 비밀번호 재설정, 삭제.
  • API 연동 — 카카오·네이버 로그인, OpenAI·Anthropic, SOLAPI(문자·알림톡), GA4, 인스타그램 키 입력란. 현재는 키 보관 단계이며, 각 기능의 실제 연동은 다음 단계입니다. 비밀키는 저장 후 값을 다시 보여주지 않으며, 비우려면 [비우기]를 체크하세요.
  • 활동 로그 — 작업 이력(최근 50건)과 직원 최근 로그인 이력을 조회합니다.

자주 묻는 질문

  1. 저장했는데 공개에 안 보여요 — 새로고침 후 확인하세요. 서브페이지에서 순서를 바꾼 경우라면, 순서의 공개 반영은 현재 메인 페이지만 지원합니다(§3 주의 참고).
  2. 순서 저장 버튼이 없어요 — 드래그해서 놓는 순간 자동 저장됩니다. 되돌리려면 [기본 순서로].
  3. 실수로 바꿨어요 — 해당 블록을 다시 열어 [기본값으로 초기화]. 순서는 [기본 순서로]. 헤더·푸터와 카테고리는 저장 전이면 [되돌리기].
  4. 이미지가 안 올라가요 — 20MB 이하 이미지·영상만 가능하며, SVG는 차단됩니다(PNG·JPG·WebP 사용).
  5. 영문(EN) 화면이 안 바뀌어요 — 콘텐츠·뉴스 본문은 현재 한국어 기준입니다. 공통 문구는 언어팩에서 EN을 직접 수정하세요.
  6. 직원이 설정·문의 메뉴가 안 보여요 — 편집자 역할은 계정 관리(설정)와 문의 관리(고객 개인정보)를 볼 수 없습니다. 어드민 계정으로 로그인하세요.
  7. 어떤 섹션은 핸들이 회색이라 안 움직여요 — 고정 배지가 붙은 섹션(예: 메인 히어로)은 위치가 고정되어 있고 내용만 편집합니다.
