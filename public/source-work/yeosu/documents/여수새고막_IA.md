## 1. 사이트맵 트리 (Site Map)

GNB = 1Depth 기준. 다국어(KO/EN)는 전 화면 공통이므로 트리에 별도 표기하지 않는다.
브랜드 하위 제품(3Depth)은 GNB에 노출하지 않고 브랜드 페이지 라인업·전체 제품 탭으로 진입한다.

```
HOME (메인)
├─ 회사소개 (ABOUT)
│  ├─ 회사개요
│  ├─ CEO 인사말
│  ├─ 회사 연혁
│  ├─ 조직·브랜드 구조
│  ├─ 품질·신뢰 (HACCP 등 인증 현황)
│  ├─ 생산공정 (생산 시설)
│  └─ 수출 실적·거래처
├─ 브랜드·제품 (BRANDS & PRODUCTS) ★핵심
│  ├─ 엄지네포장마차 — 제품 5종 (라인업 슬라이더)
│  │  ├─ 꽥! 간장 꼬막장
│  │  ├─ 꽥! 양념 꼬막장
│  │  ├─ 꽥! 양념 가리비장
│  │  ├─ 꽥! 양념 전복장
│  │  └─ 강릉엄지네 꼬막무침 밀키트
│  ├─ 칠산꽃게장 — 제품 3종 + 출시예정 1 (라인업 그리드)
│  │  ├─ 간장 꽃게장
│  │  ├─ 양념 꽃게장
│  │  ├─ 꽃게탕
│  │  └─ 간장·양념 대하장 (출시예정)
│  ├─ 여수올림 (원물 B2B) — 제품 3종 (라인업 그리드)
│  │  ├─ 생물 꼬막
│  │  ├─ 자숙 새꼬막살
│  │  └─ 자숙 가리비살
│  ├─ 전체 제품 (브랜드별 탭: 모두보기/엄지네/칠산/여수올림/신제품)
│  └─ 신제품 예고 (전체 제품의 #new 필터 상태)
├─ 수출정보 (EXPORT)
│  ├─ 수출 제품 카탈로그
│  ├─ 수출국 현황
│  ├─ 인증·규격 정보
│  └─ OEM/ODM 안내
├─ 뉴스·IR (NEWS)
│  ├─ 공지사항
│  ├─ 보도자료
│  └─ 전시회·박람회
└─ 문의 (CONTACT)
   ├─ 바이어 문의 (EN)
   ├─ 국내 거래처 문의
   ├─ OEM/ODM 문의
   ├─ 상담 문의
   └─ 오시는 길
```

- GNB "브랜드·제품" 2Depth 구성(구현 스펙 §2와 동일): 엄지네포장마차 / 칠산꽃게장 / 여수올림 / 전체 제품 / 신제품 예고 — 5항목.
- 각 브랜드 페이지에는 라인업 하단에 "다른 브랜드 둘러보기" 크로스 링크 스트립이 있어 브랜드 간 수평 이동을 지원한다.
- 부가: 시스템/정책 화면(에러·약관 등)은 GNB에 노출하지 않으나 구축 범위에 포함한다(§6 표 참조).

## 3. 화면 ID 체계

- 접두어: `AB`(회사소개) `BR`(브랜드 허브) `PR`(제품) `EX`(수출) `NW`(뉴스) `CT`(문의) + 일련번호. **v1.0 ID를 그대로 유지**하되 소속만 재편 — `BR-*`와 `PR-*`는 v2.0에서 모두 1Depth "브랜드·제품" 아래에 있다. 접두어는 GNB 소속이 아니라 **화면 성격**(브랜드 허브 vs 제품 화면)을 가리킨다.
- 제품 상세: `PR-002` 단일 정의 + 인스턴스 `PR-002-01`~`PR-002-12`(§2-2). 인스턴스의 상위(부모)는 소속 브랜드 화면(BR-001~003)이다.
- 결번 규칙: 폐지된 ID(PR-003~008, BR-004)는 재사용하지 않는다. 신규 화면은 접두어별 다음 번호부터 부여(예: 회사소개 신규 → AB-007, AB-008…).
- 이 ID는 기능정의서의 화면ID·기능ID(`PR-002-F01` 등)와 동일하게 연결된다.

## 4. 확장 규칙 (스케일링) — v2.0 신설

브랜드·제품이 늘어나도 IA를 바꾸지 않고 **표시 규칙만으로 흡수**한다. 기준표(구현 스펙 §3과 동일 기준):

| 영역 | 현재 수량 | 확장 규칙 |
|---|---|---|
| 메인 브랜드 슬라이드 (HOME) | 3 | 브랜드 수만큼 슬라이드·도트 추가(Swiper 기존 구조 유지). 4개 이상이어도 동일 패턴 |
| GNB "브랜드·제품" 2Depth | 5항목 (브랜드 3 + 전체 제품 + 신제품 예고) | 브랜드 추가 시 항목만 추가(세로 나열). **최대 8항목 권장** |
| 브랜드 페이지 제품 라인업 (BR-00x) | 3~5장 | **카드 4장 이하: 그리드 / 5장 이상: 슬라이더 자동 전환**(화살표+도트, PC 4장 / 태블릿 2~3장 / 모바일 1.2장 노출) + "총 N종" 카운트 자동 표기 |
| 전체 제품 탭바 (PR-001) | 5탭 (모두보기+브랜드 3+신제품) | 탭 5개 초과 시 **가로 스크롤 탭바**(overflow-x:auto + 스크롤 스냅) |
| 브랜드 크로스 링크 스트립 (BR-00x 하단) | 카드 2장 (나머지 브랜드) | 가로 flex(wrap) — 브랜드가 늘면 카드만 추가 |

### 확장 시나리오 3종

**시나리오 1 — 브랜드 4개가 될 때** (신규 브랜드 1개 추가)

| 화면 | 표시 변화 |
|---|---|
| HOME 메인 | 브랜드 슬라이드 3 → 4장, 도트 4개. 신규 슬라이드에도 제품 미니 스트립 + "제품 N종" 뱃지 동일 적용 |
| GNB | 브랜드·제품 2Depth 5 → 6항목 (권장 한도 8 이내, 구조 변경 없음) |
| PR-001 전체 제품 | 탭 5 → 6개 → **가로 스크롤 탭바 발동**. 신규 브랜드 카드 그룹이 브랜드 순 정렬에 추가 |
| BR-00x 브랜드 페이지 | 크로스 링크 스트립 카드 2 → 3장 (flex wrap, 코드 변경 없이 카드만 추가) |

**시나리오 2 — 브랜드 5개가 될 때**

| 화면 | 표시 변화 |
|---|---|
| HOME 메인 | 브랜드 슬라이드 5장·도트 5개 — 여전히 동일 슬라이드 패턴 (개편 불필요) |
| GNB | 2Depth 7항목 (브랜드 5 + 전체 제품 + 신제품 예고). 8항목 권장 한도 도달 직전 — **6번째 브랜드부터는 GNB 2Depth를 "브랜드 전체보기" 허브 화면으로 대체 검토** (IA 재검토 트리거) |
| PR-001 전체 제품 | 탭 7개, 가로 스크롤 탭바로 흡수. 스크롤 스냅으로 탭 단위 이동 |
| BR-00x 브랜드 페이지 | 크로스 링크 카드 4장, 2행 wrap 허용 |

**시나리오 3 — 한 브랜드의 제품이 9개 이상이 될 때** (예: 칠산꽃게장 4 → 9장)

| 화면 | 표시 변화 |
|---|---|
| BR-002 등 해당 브랜드 페이지 | 라인업 카드 5장 이상이므로 **그리드 → 슬라이더 자동 전환**(초기화 시 카드 수 카운트로 조건 분기). 9장이면 PC 4장 노출 + 도트 증가, "총 9종" 카운트 자동 갱신. 별도 IA·퍼블리싱 개편 불필요 |
| HOME 메인 | 해당 브랜드 슬라이드의 미니 스트립은 **썸네일 3~4개 고정 + "제품 9종" 뱃지만 갱신** (썸네일 수는 늘리지 않음) |
| PR-001 전체 제품 | 해당 브랜드 탭의 카드만 증가(탭 수 불변). 브랜드 순 정렬 유지. 카드 20장+ 시 페이지네이션/더보기 도입 검토 (IA 재검토 트리거) |

> 재검토 트리거 요약: **브랜드 9개 이상**(GNB 세로 나열 한계) 또는 **단일 탭 카드 20장 이상**(목록 스캔 한계)이 되면 표시 규칙이 아닌 IA 자체를 재검토한다. 그 전까지는 위 규칙으로 무개편 흡수.

## 5. 다국어 구조 (요약)

- KO 기본 / EN 필수. 전 화면 공통(기능정의서 공통 요구사항 CMN-* 참조).
- URL 전략: 서브패스 — 현행 KO는 `/kr/...`로 구축되어 있으며, EN은 `/en/...`으로 **동일 트리(브랜드 하위 제품 구조 포함)를 미러링**한다. 언어 전환은 GNB 상시 노출.
- 바이어 문의(CT-001)는 영문이 기본 진입으로 설계. 브랜드 페이지의 수출가능 태그·수출정보 링크는 EN에서 바이어 동선(카탈로그 EX-001 → 문의 CT-001)으로 연결.

## 7. 작성 점검 결과

- 메뉴 구성 MECE 재확인: 제품소개·브랜드 통합으로 v1.0의 "같은 제품이 제품소개와 브랜드 양쪽에서 다른 축으로 노출"되는 중복 축 제거. 회사/브랜드·제품/수출/뉴스/문의로 상호배타 유지.
- Depth는 GNB 기준 2Depth, 콘텐츠 진입 기준 최대 3Depth(브랜드 → 제품 상세). 3Depth는 GNB 미노출·페이지 내 라인업으로만 진입해 탐색 부담을 늘리지 않음.
- 제품-브랜드 소속의 단일 진실은 §2-2 매핑(구현 스펙 §1과 동일). 밀키트=엄지네 정정 반영 완료. 메인 미니 스트립·전체 제품 카드·브랜드 라인업 3곳 수량(5/4/3) 일치 여부를 검수 항목으로 유지.
- 레거시 링크 무결성: `#jang`/`#mealkit`/`#raw` 별칭 라우팅과 폐지 화면 결번 관리로 외부 유입·북마크 끊김 없음(§2-3).
- 빈 상태(검색 0건, 브랜드 내 제품 0종 — 신규 브랜드 개설 직후), 에러(404/500), 정책 페이지 누락 점검 완료 — §4 확장 규칙·§6 표에 반영.
- 모든 화면ID가 기획서 요구사항(REQ-*)과 연결되는지 확인. 폐지 ID의 기능ID(PR-003-F* 등)는 기능정의서에서 이관·폐기 처리 필요(후속 작업). 고아 화면 없음.
